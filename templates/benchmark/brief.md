# Benchmark brief: two-module word report

Disposable fixture generated by `scripts/benchmark.py`. It gives one small,
comparable team trial with hard acceptance criteria. One run is not a quality
claim; compare repeated comparable runs against a single-agent baseline first.

## Frozen interface (agreed before any worker starts)

`textstats.py`

```python
def word_count(text) -> int: ...
def top_words(text, n) -> list[tuple[str, int]]: ...
```

`report.py` (imports `textstats`)

```python
def render(text, limit=3) -> str: ...
```

`top_words` lowercases, orders by count descending then alphabetically, and
returns at most `n` entries. `render` joins `"word: count"` lines with a newline
and adds no trailing newline. Empty input yields `[]` and `""`.

## Requirements

See `requirements.json`. Requirement ids are stable and acceptance maps to them.

## Suggested roles

| Role | Owns | Notes |
| --- | --- | --- |
| worker-a (DeepSeek) | `task/textstats.py` | R1, R2 |
| worker-b (DeepSeek) | `task/report.py` | R3 |
| verifier (DeepSeek, different actor) | read-only | reproduce R4 |
| Selected reviewer | review and acceptance | confirm R1-R5 against the diff and evidence |

`task/tests/` and `task/integration_check.py` ship with the fixture and belong to
no worker. Editing them invalidates the grade.

## Acceptance

```text
python3 scripts/benchmark.py grade --workspace <this>/task --out <this>/report.json
```

The grade runs the shipped tests, the integration check, a standard-library
import scan, and a fixture-integrity check, then maps each requirement to its
checks. A passing grade means the files satisfy R1-R5 in this checkout. It says
nothing about team behaviour; record lifecycle events and manual review notes
separately with `--observations`.

## Ledger scenarios to watch

Express the same run as a task ledger. The invariant tests in
`tests/test_workflow.py` cover the four failure modes that matter most here:
missing information, a success claim contradicted by evidence, conflicting
writes, and a revised artifact invalidating acceptance.
